# Diseno y Brand System - SwipeForge

## 1. Identidad Visual XookTech
- **Fondo Oscuro**: `#0A0F1E`
- **Fondo Claro**: `#F5F5F7`
- **Acento Tecnico Naranja**: `#FF6B00`
- **Gradiente de Portada**: `linear-gradient(135deg, #FF9A56 0%, #FF6B35 50%, #E85D04 100%)`
- **Texto en Alto Contraste**: `#FFFFFF`

## 2. Tipografias Locales
- **Borscha**:
  - `BorschaBold` para titulares (`h1`, `title`), ganchos y elementos de maximo peso visual.
  - `BorschaRegular` para cuerpos de texto editorial y listas.
- **Rostex**:
  - `RostexRegular` para logotipos, kickers superiores y pie de pagina con espaciado amplio (`letter-spacing: 2px - 6px`).

## 3. Relaciones de Aspecto
- **4:5 (1080x1350 px)**: Formato principal recomendado para feed vertical de Instagram.
- **1:1 (1080x1080 px)**: Formato cuadrado universal.
- **9:16 (1080x1920 px)**: Formato vertical para Stories y Reels.

## 4. Margenes y Safe Zones
- Padding obligatorio interior: minimo 80px.
- Margen superior seguro: 120px libres de elementos criticos.
- Margen inferior seguro: 140px libres de elementos criticos.
